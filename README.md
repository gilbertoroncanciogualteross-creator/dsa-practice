# DSA Practice

This repo is for solving DSA problems. I practice DSA to build a solid foundation in problem solving.

## How I solve each problem

- Phase A: First, I solve it the simplest way, usually with two nested loops, without thinking about optimization yet.
- Phase B: After that, I try to optimize the code and make it more efficient.
- The complexity comment at the top of each file shows the time and space complexity, and helps me understand how these concepts relate to each problem.
